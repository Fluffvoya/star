# 引擎目录规则

适用于 `Engine/` 下的引擎源码、着色器、配置和内置资产。目录和模块未创建前，不把文档中的目标误认为已存在。

- 按实现方案的 `Public/`、`Private/`、`Tests/` 划分模块。公共头独立可编译；运行时不依赖编辑器；跨模块依赖按架构基线登记。
- EnTT 只用于 Scene 私有实现。SDK 和游戏侧生成代码不包含 EnTT；游戏通过 Star 的句柄、组件查询和结构命令使用 ECS。
- 明确数据所有权、线程与阶段边界。跨帧使用句柄或 GUID，不缓存借来的组件指针；遍历期间的结构修改统一入队。热重载前清理对旧模块的代码和数据引用。
- 可恢复错误用 `std::expected` 或项目对应的错误接口，禁止异常跨模块传播。修改 SDK、反射、着色器或序列化时，验证消费者和失败路径。
- 生成文件由生成规则产出，不手工修改。第三方源码遵循上游格式；引入、升级或打补丁时记录来源、固定版本和许可证。
- 优先运行改动模块的本地测试。改 SDK、生成器或加载路径时，验证独立游戏模块或干净构建；改渲染后端时报告实际启用的 RHI，不把回退当作该后端通过。
