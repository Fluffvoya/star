# ADR-0012：网络

- 状态：已确认
- 日期：2026-11-20
- 关联：[Star Engine 实现方案](../architecture/implementation-plan.md) §1.3、§2.1

## 背景

网络同步会显著扩大运行时、序列化、物理确定性和编辑器工具的范围。第一版目标是稳定的单机引擎基础设施。

## 备选方案与后果

- 内置复制、RPC 和传输层。使用方便，但需要确定服务器模型、协议、权限、预测和回滚。
- 选择一个第三方网络框架并封装。能缩短传输实现，但仍需确定游戏对象复制语义和生命周期。
- 不内置网络模块，保留扩展边界。引擎范围更小，网络游戏由项目自行选择库和协议。

## 决定

第一版不提供网络模块、复制标记或 RPC。对象提供稳定 GUID，模拟逻辑与表现逻辑保持可分离，游戏项目可以自行接入第三方网络库。

## 后果

引擎不保证跨机器状态同步、网络确定性或传输 ABI。GUID、序列化和物理接口应避免阻断未来的项目级网络实现。

## 验收边界

M0-M10 不以网络功能作为验收项。任何新增网络相关运行时能力都必须单独提交架构决策。
