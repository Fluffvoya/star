# M5-05 场景视口与选择

- 分支：`feat/m5-scene-viewport`
- 验证环境：Linux x64、`linux-dev`、llvmpipe Vulkan。Windows x64、macOS arm64 未验证。

## 交付

- 中央视口在原有停靠布局中打开，显示场景网格、世界轴及对象原点。视口支持透视与正交、右键视角控制、WASD 和 QE 移动、滚轮及 F 聚焦。
- 点击对象标记更新文档的 GUID 选择集，与层级及检视器共用同一状态。Ctrl 点击切换选择，点击空白处清除选择。
- 网格直接绘制到随面板大小变化的 RHI 纹理。ImGui 绘制按纹理 ID 绑定采样视图，Vulkan 释放已销毁的绑定组描述符，避免反复调整尺寸耗尽描述符池。

## 验证

| 项目 | 结果 |
| --- | --- |
| `linux-dev` 构建及着色器编译 | 通过 |
| 软件 Vulkan CTest | 19/19 通过 |

| 现有布局与呈现 | 用 M5-04 保存的停靠布局打开三对象场景，开启 Vulkan 同步验证绘制 30 帧，截图可见中央网格与对象标记 |

本阶段显示编辑网格和对象原点。场景网格资产渲染、变换操纵器、PIE 及热重载仍待交付。界面检查覆盖布局与绘制，输入操作尚未做自动化验证。
