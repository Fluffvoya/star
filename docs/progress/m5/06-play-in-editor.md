# M5-06 编辑器内运行

- 分支：`feat/m5-play-in-editor`
- 验证环境：Linux x64、`linux-dev`、llvmpipe Vulkan。Windows x64、macOS arm64 未验证。

## 交付

- Play 从当前编辑场景生成内存二进制快照，在独立的 World 中恢复同一组 GUID、已注册的类型与未知数据，再启动运行。编辑文档保留未保存数据、选择和撤销记录。
- Play 菜单支持暂停、继续、单步和停止。场景视口使用首个启用且有效的 Camera。Simulation Camera 允许从编辑相机观察运行中的对象。
- 运行期间层级和检视器指向运行副本。检视器可将所选对象的 Transform 写回编辑文档，操作可撤销。停止后丢弃运行副本并返回编辑世界。
- 通过 `--game-module=<path>` 加载独立游戏模块。运行世界的模块注册和系统实例独立于编辑世界。

## 验证

| 项目 | 结果 |
| --- | --- |
| `linux-dev` 构建 | 通过 |
| 软件 Vulkan CTest | 19/19 通过 |
| 独立游戏模块 | 二进制快照保留未保存的改名、对象选择、未知组件和未知字段。运行一帧只改变运行世界的游戏组件，停止后编辑文档的撤销及重做仍有效。 |

当前编辑器持有一个场景文档。PIE 与编辑器使用同一动态库文件，模块内部的静态状态由进程共享。保留修改支持 Transform。视口仍显示网格及对象原点。菜单交互与游戏相机尚未做自动化验证。
