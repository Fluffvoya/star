# M5-04 编辑器编辑与保存流程

- 分支：`fix/m5-editor-workflow`
- 验证环境：Linux x64、`linux-dev`、llvmpipe Vulkan。Windows x64、macOS arm64 未验证。

## 交付

- 新建、打开另一场景或退出前，脏文档会提示保存、放弃或取消。保存失败时保留当前文档并在提示框显示错误。
- 新场景的建议文件名已存在时，使用带数字后缀的文件名。场景文件先写入同目录中的临时位置，关闭成功后再替换目标。写入或替换失败时保留脏标记及原保存路径。
- 层级面板按父子关系展开，使用对象 GUID 维持节点标识。编辑器重启时复用已有的停靠布局。
- 编辑器窗口开启 SDL 文本输入。检视器使用反射的格式化和解析接口提交数字，回车后生成属性命令。文本输入期间，Ctrl+Z 与 Ctrl+Y 留给文本控件。
