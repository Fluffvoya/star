# M5-08 变换操纵器

- 分支：`feat/m5-transform-gizmo`
- 验证环境：Linux x64、`linux-dev`、llvmpipe Vulkan。Windows x64、macOS arm64 未验证。

## 交付

- 在编辑视口选择对象后，可用 W、E、R 或工具栏切换移动、旋转和缩放。工具栏支持本地轴及吸附，默认步进为 0.5 米、15 度及 0.1 倍。
- 拖动期间只预览。松开鼠标提交一条变换命令，Escape 取消。引擎按父节点变换把目标姿态换算为局部 TRS，拒绝无法表示的剪切和奇异矩阵。
- 修复撤销删除子对象时错误地用世界姿态重挂的问题。恢复后的局部姿态和 GUID 保持一致。
- 引入固定提交的 ImGuizmo 源码及 MIT 许可证。来源记录在 [依赖说明](../../../engine/source/third-party/imguizmo/README.md)。
