# M1-03 生成器集成与联合验收

2026-11-20，分支 `task/m1-generated-reflection-20261120`。

## 交付

- `star_generate_reflection()` 接收模块的头文件列表和解析参数，将 StarHeaderTool 生成的 C++ 和头文件加入目标。生成器通过 libclang 取得实际包含文件，Ninja 通过 depfile 跟踪传递依赖。
- 生成的模块注册入口提供私有属性访问、公开基类关系、枚举项、无参数成员方法调用，以及类型和属性注解。类型 ID 使用完全限定名的 XXH3 64 位哈希，注册时检查当前名和旧名冲突。
- YAML 和二进制归档支持生成的私有和继承属性、枚举、`std::vector`、`std::array` 及字符串键映射。容器中出现无法转换的值时，保留模式保存整项原始字段并报告元素路径。
- 手工注册的内置类型包含数字、字符串、GUID、Name、路径、向量和四元数。开发和单体构建均私有链接 xxHash，发布依赖继续使用仓库的 vcpkg baseline。
- 归档支持按需省略默认值。`CustomSerialize` 类型可通过 `Archive::value()` 自定义字段，YAML 和二进制共享该回调。
