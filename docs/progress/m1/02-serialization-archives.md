# M1-02 序列化归档阶段报告

2026-11-20，分支 `task/m1-serialization-20261120`。

## 交付

- 新增独立的 `Star::Serialization` 模块，YAML 和小端二进制快照共享拥有数据所有权的文档结构。快照记录类型全名、版本、字段名和值的类别。
- 反射转换支持布尔、整数、浮点数、字符串和带元数据的嵌套结构。整数按实际字段类型做范围校验，`Transient` 字段在加载和保存时均跳过。
- 加载支持旧类型名、旧字段名及调用方提供的升级回调。保留模式将未知字段和无法转换的值连同诊断交还调用方，保存时可将这些数据写回。未注册类型可作为独立文档往返。
- 严格模式遇到未知字段或转换失败时返回字段路径，反射对象在所有字段处理成功后才更新。二进制读入检查格式版本、长度边界和重复键。

## 验收边界

本阶段使用手工声明的反射元数据验证归档。生成的运行时注册代码、继承字段、枚举和容器属性仍需联合验收。YAML 归档接受映射、序列和标量，遇到锚点、别名或自定义标签会返回错误。对象加载需要可复制且支持无异常交换的反射类型。Windows x64 和 macOS arm64 待对应主机验证。
