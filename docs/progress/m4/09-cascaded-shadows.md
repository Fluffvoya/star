# M4-09 方向光级联阴影报告

- 日期：2026-11-27
- 分支：`feat/m4-cascaded-shadows`
- 状态：Linux x64 软件 Vulkan 本地验证完成

## 本阶段交付

- 为方向光渲染四个 1024×1024 深度层。按混合深度分割拟合视锥切片，阴影深度范围包含场景投影体。
- 前向着色按片元视深选择级联，通过 3×3 PCF 和接收平面深度偏移计算阴影可见性。阴影衰减方向光贡献，点光照保持独立。

## 验证结果

- Intel Core i7-14650HX、llvmpipe（LLVM 23.1.5）、Slang v2026.18.2，开启 Vulkan 验证层。全部 15 项 CTest 通过。
- 对比同一固定场景的分簇基线，新增阴影在地面上随三个遮挡体出现。逐像素对比显示 3,688 个像素发生变化，读回图像中地面受光区未出现大面积自阴影条纹。
- 960×640，预热 137.940 ms，随后 30 帧平均 GPU 时间 4.167 ms，包含阴影、深度、分簇、前向着色和读回拷贝。
- Windows x64、macOS arm64 和硬件 GPU 尚未验证。
