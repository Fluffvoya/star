# M4-10 基于图像的光照报告

- 日期：2026-11-27
- 分支：`feat/m4-image-based-lighting`
- 状态：Linux x64 软件 Vulkan 本地验证完成

## 本阶段交付

- 样例从固定 HDR 天空辐亮度构建环境贴图。对辐亮度做 GGX 重要性采样生成七级镜面预滤波数据，对漫反射使用二阶共九项球谐系数。
- 环境贴图以线性浮点格式上传，片元按材质粗糙度选择 mip 并计算环境镜面。球谐漫反射与方向光和分簇点光叠加，再经过色调映射。

## 验证结果

- Intel Core i7-14650HX、llvmpipe（LLVM 23.1.5）、Slang v2026.18.2，开启 Vulkan 验证层。全部 15 项 CTest 通过。
- 检查 960×640 读回图，与级联阴影阶段的同场景基线比较。阴影区的样点 RGB 从 (61, 65, 68) 变为 (111, 130, 153)，背景样点保持 (44, 49, 61)。
- 30 帧平均 GPU 时间 3.463 ms，预热 161.770 ms。GPU 时间包含阴影、深度、分簇、着色和读回拷贝，环境数据在初始化时生成。
- Windows x64、macOS arm64 和硬件 GPU 尚未验证。

## 阶段边界

- 当前使用固定环境和近似环境 Fresnel。外部 HDR 环境资产、完整运行时材质绑定和大型标准场景验收属于后续工作。
