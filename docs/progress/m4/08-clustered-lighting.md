# M4-08 GPU 分簇光照报告

- 日期：2026-11-27
- 分支：`feat/m4-clustered-lighting`
- 状态：Linux x64 软件 Vulkan 本地验证完成

## 本阶段交付

- 前向样例在深度预通道之后调度计算着色器，将视锥分成 16×9×24 个簇。深度切片使用对数分布。
- 计算着色器按点光源影响球和簇边界分配灯光索引。片元着色只遍历所属簇的列表，通过 GPU 屏障读取计算结果。
- 固定场景包含三个带有限作用范围的彩色点光源。每簇最多保留八项，样例配置的灯光数低于该上限。

## 验证结果

- 使用 Intel Core i7-14650HX、llvmpipe（LLVM 23.1.5）、Vulkan 验证层和 Slang v2026.18.2，在 960×640 渲染固定场景。全部 15 项 CTest 通过。
- 把同一片元着色器临时改为遍历全部点光源，重新编译并输出参考图。两种路径的 PPM 文件逐字节一致。
- 预热 84.748 ms，随后 30 帧平均 GPU 时间 2.227 ms，包含深度、分簇、着色和读回拷贝。
- Windows x64、macOS arm64 和硬件 GPU 尚未验证。
