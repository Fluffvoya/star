# M4-04 运行时资产加载基础报告

- 日期：2026-11-27
- 分支：`feat/m4-asset-loading`
- 状态：Linux x64 本地验证完成

## 本阶段交付

- 新增 `Star::Asset` 运行时模块。可将文件路径登记到 GUID，再通过同一入口阻塞或异步读取二进制载荷。
- 同一 GUID 的并发在途请求共享条目和结果。Jobs 后台执行读取，管理器在所属线程发布结果。句柄区分加载中、就绪和读取失败，并保持已发布数据的生命周期。
- 管理器按帧回收无外部引用的条目。关闭时收尾在途读取，外部句柄可继续访问已发布的数据或错误。

## 验证结果

- Linux x64 Development 构建成功，全部 15 项 CTest 通过，包括公共头独立编译检查。
