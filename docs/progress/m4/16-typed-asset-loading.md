# M4-16 类型化资产加载与端到端验证报告

- 日期：2026-11-27
- 分支：`feat/m4-typed-asset-loading`
- 状态：Linux x64 软件 Vulkan 端到端验证完成

## 本阶段交付

- `AssetRef<T>` 以 GUID 引用静态模型或纹理。类型化强引用句柄可查询状态、数据和错误。同一 GUID 请求共享后台读取及解码。
- 管理器在所属线程发布结果。错误区分登记类型不匹配、读取失败和解码失败，句柄可以在管理器销毁后保留已加载数据。
- Vulkan 样例支持通过类型化运行时加载器直接读取静态模型派生文件。

## 验证结果

- Linux x64 Development 全部 15 项 CTest 通过。专项验证类型不匹配、失败状态、请求复用以及管理器销毁后的资产访问。
- 将 [贴图标准场景](12-gltf-material-textures.md) 导入 DDC，第一次未命中，第二次命中。派生载荷含五个网格部件和两张贴图。
- Intel Core i7-14650HX、llvmpipe（LLVM 23.1.5）、Vulkan 验证层，在 960×640 通过派生文件加载并渲染。读回 PPM 与直接导入源 GLB 的结果逐字节一致。
- 预热 351.882 ms，随后 30 帧平均 GPU 时间 126.920 ms。Windows x64、macOS arm64 和硬件 GPU 尚未验证。

## 阶段边界

- 当前强引用支持派生静态模型和 RGBA8 纹理。本地文件以外的 VFS、独立依赖图、场景预加载和异步 GPU 上传仍待接入。
