- 日期：2026-11-27

## 本阶段交付

- 材质档案以 GUID 引用着色器，保存参数映射、混合模式、双面、深度测试和着色模型。材质实例通过父材质 GUID 继承数据并覆盖参数。
- 着色器 GUID 与渲染状态组成可比较的变体键。同一材质上的参数覆盖保留变体键，渲染状态变化会生成不同的键。
- 材质及实例使用同一套版本化 YAML 与二进制归档。编辑期保留未知的档案字段和渲染状态字段，严格读取拒绝这些字段并给出字段路径。
