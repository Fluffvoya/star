# M4-01 资产数据库与元数据报告

- 日期：2026-11-27
- 分支：`feat/m4-asset-registry`
- 状态：Linux x64 本地验证完成

## 本阶段交付

- 新增 `Star::AssetPipeline` 工具模块，复用现有 GUID 与 YAML API。
- `.meta` 编解码支持源资产 GUID、导入器、导入器版本、导入设置和子资产。元数据及子资产的未知字段可随 YAML 往返保留。
- 递归扫描内容目录中的 `.meta`，按源文件相对路径查找元数据，按源资产或子资产 GUID 反查位置。源文件与侧车一起移动后，重新扫描即可解析至新路径。
- 扫描在校验通过后更新索引。无效元数据、孤立侧车、重复 GUID 或 I/O 错误会返回诊断，并保留上一次成功扫描的结果。
