# M0 Jobs TaskGraph 阶段报告

- 日期：2026-11-19
- 实现分支：`feat/m0-task-graph`
- 范围：任务依赖声明、调度和失败传播

## 已交付

- `TaskGraph` 支持添加带优先级的任务和声明前置依赖。重复依赖幂等，跨图句柄、无效任务和环依赖在执行前返回错误。
- 运行时调度复用现有 `Jobs` 队列和工作线程。没有依赖的节点立即提交，前置任务完成后释放后继节点。失败或抛出异常的节点会阻止其后继节点，独立分支仍会排空执行。
- `run()` 等待图内任务全部排空后返回。图可以在一次运行完成后重复执行。运行期间禁止添加任务和依赖，也禁止递归执行同一图。
- 任务函数返回 `true` 表示成功，返回 `false` 或抛出异常表示失败。异常在任务边界内收集，不跨模块传播。
