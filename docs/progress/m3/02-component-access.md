# M3-02 组件注册与查询阶段报告

- 日期：2026-11-26
- 分支：`feat/m3-component-access`
- 状态：Linux x64 本地验证完成

## 本阶段交付

- Scene 按 Star 反射类型 ID 注册组件，校验元数据、存储对齐和重复类型。组件存储归 Scene 所有，游戏侧使用 Star SDK 访问。
- 多组件查询遍历最小的匹配池，按对象句柄返回组件借用。查询可写入已声明为可变的组件，并可排队增删组件和销毁对象。
- 组件增删按提交顺序可见。排队时构造新增值并准备存储，提交阶段可以直接接管值。正在查询的 Scene 禁止立即创建、卸载或更改组件注册。
- 按模块标识注销组件时，回收已提交的值、待提交的值和注册元数据，之后可以重新注册。

## 验证结果

- Linux x64 Development 共享库构建通过全部 12 项 CTest，含 Scene 和公共头独立编译。
- 单体静态构建通过 Scene 专项及公共头独立编译。
- 测试覆盖多组件过滤、读写借用、显式初值、过对齐存储、查询中延迟修改、即时结构修改保护，以及注销时销毁组件后重新注册。
- Windows x64、macOS arm64 和外部游戏动态库尚未在本阶段验证。
