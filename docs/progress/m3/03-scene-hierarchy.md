# M3-03 内置组件与层级变换阶段报告

- 日期：2026-11-26
- 分支：`feat/m3-scene-hierarchy`
- 状态：Linux x64 本地验证完成

## 本阶段交付

- GameObject 默认拥有局部 Transform、派生 WorldTransform 和 Hierarchy。Camera、MeshRenderer 与 Light 可通过通用组件接口添加。
- 父子关系在结构提交时生效。排队时校验同场景归属和待提交关系中的环，提交时维护子节点链、深度和兄弟顺序。销毁父对象会标记并清理整棵子树。
- 局部变换被写入后，Scene 在提交边界按父节点先于子节点的顺序传播世界变换。重新挂接可选择保留局部变换或世界变换。矩阵奇异或无法分解为 TRS 时，提交返回错误并保留原父子关系。
- GameObject 提供局部变换读写、世界变换读取、父节点查找、延迟重新挂接和延迟销毁接口。

## 验证结果

- Linux x64 Development 共享库构建通过全部 12 项 CTest。单体静态构建通过 Scene 专项和公共头独立编译。
- Scene 专项覆盖多层传播、父节点修改、跨场景与环检测、子树销毁、兄弟顺序、旋转及负缩放下保留世界变换，以及奇异矩阵导致的失败。
- Windows x64 与 macOS arm64 尚未在本阶段验证。
