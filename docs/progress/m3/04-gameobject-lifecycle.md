# M3-04 GameObject 生命周期阶段报告

- 日期：2026-11-26
- 分支：`feat/m3-gameobject-lifecycle`
- 状态：Linux x64 本地验证完成

## 本阶段交付

- Scene 支持排队生成 GameObject 子类。生成令牌在提交后解析为对象句柄，销毁后失效。
- 对象附加到 Scene 并安装默认组件后调用创建回调。生命周期包括创建、启用、开始运行、结束运行、停用和销毁。
- World 管理运行状态。层级活动状态按父节点先于子节点传播，停止运行、对象销毁和场景卸载提供各自的结束原因。
- 生命周期回调可将结构命令排入下一批。场景卸载时关闭命令入口，已创建的对象在组件仍可访问时收到销毁回调。

## 验证结果

- Linux x64 Development 共享库构建通过全部 12 项 CTest，单体静态构建通过 Scene 专项和公共头独立编译。
- Scene 专项覆盖子类创建、生命周期顺序、回调命令延迟、令牌失效、父级活动继承和结束原因。
- Windows x64 与 macOS arm64 尚未在本阶段验证。
