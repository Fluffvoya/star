# M3-07 独立游戏模块与 Linux 验收报告

- 日期：2026-11-27
- 分支：`feat/m3-game-module`
- 状态：M3 Linux x64 本地验收完成

## 本阶段交付

- World 通过 `StarGetModuleDescriptor` 加载游戏动态库，校验 ABI 版本、模块身份和类型元数据。模块可注册组件、GameObject 工厂与 System。
- 已存在和新建的 Scene 均可读取模块组件。场景加载通过已注册的工厂创建游戏对象，恢复组件数据后调用创建回调。
- 模块卸载前清理 System、对象、组件、待提交命令和反射注册，再释放动态库。启动失败回滚注册。卸载时，未排队销毁的引擎自有子对象脱离模块自有父对象并保留。
- 游戏测试库使用独立 CMake 工程，仅从 Star SDK 公共头文件和引擎链接库构建。

## M3 验收结果

| 验收项 | Linux x64 结果 |
| --- | --- |
| SDK 边界 | 独立工程在无 EnTT include 路径的情况下注册 GameObject 和组件 |
| 组件共享 | 引擎设置 Score，游戏对象 Tick 和模块 System 更新同一个值 |
| 阶段边界 | 同阶段读者看不到排队新增的组件，下一阶段可见 |
| 场景往返 | GUID、父子关系、对象顺序和可识别的游戏组件往返，未知数据在保留模式下往返 |
| 模块回收 | 启动失败回滚。卸载移除已提交和待提交值，Linux 动态加载器确认库已释放，随后可重新加载和注册 |

- Linux x64 Development 单体静态构建通过 Scene 专项和公共头独立编译检查。
