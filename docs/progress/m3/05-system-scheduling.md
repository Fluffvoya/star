# M3-05 帧阶段与系统调度报告

- 日期：2026-11-27
- 分支：`feat/m3-system-scheduling`
- 状态：Linux x64 本地验证完成

## 本阶段交付

- World 按帧阶段运行 GameObject 和 System，并在阶段结束提交 Scene 命令、更新层级活动状态和传播变换。Physics 阶段使用可配置的固定步长和每帧步数上限。
- GameObject 可开启 Tick、选择 Tick 组并声明同场景前置对象。调度检测循环依赖，跳过未开始运行、未激活或正在销毁的对象。
- System 可声明阶段、读写组件、显式依赖、并行和编辑模式运行。兼容的并行系统交给 Jobs TaskGraph，存在组件冲突或显式依赖的任务按依赖排序。
- SystemContext 校验查询权限，并收集结构命令。任务完成后由场景所有线程提交结构修改。

## 验证结果

- Linux x64 Development 共享库构建通过全部 12 项 CTest。单体静态构建通过 Scene 专项和公共头独立编译。
- 新测试覆盖对象前置与循环检测、系统依赖、读写权限、同阶段的延迟可见性与固定步上限。
- Windows x64 与 macOS arm64 尚未在本阶段验证。
