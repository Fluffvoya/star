# M2-04 Vulkan 命令池与同步提交阶段报告

- 日期：2026-11-22
- 分支：`task/m2-phase-01-20261122`
- 状态：Linux x64 本地验证完成，Vulkan 资源后端尚未开始

## 本阶段交付

- 为 `VulkanContext` 增加一次性图形命令缓冲提交入口。
- 每次提交创建命令池和命令缓冲，完成 begin/end 录制，并用 fence 等待 GPU 完成后按依赖顺序释放对象。
- 增加命令池、命令缓冲、fence、队列提交和等待函数的运行时加载与缺失入口诊断。
- 在没有可用 Vulkan 设备、命令入口或提交失败时返回 `std::expected` 错误。
- 增加空命令缓冲提交测试，覆盖逻辑设备创建后的最小同步闭环。

## 验证结果

Linux x64 `linux-dev` 预设的完整构建和 CTest 共 11 项全部通过。当前主机完成空命令缓冲录制、提交和 fence 等待。

## 阶段边界

本阶段没有接入 RHI `CommandList`、VMA、缓冲区和纹理分配、交换链呈现或渲染通道。提交接口暂时用于后端启动验收，资源和图形命令映射属于后续阶段。Windows x64 和 macOS arm64 尚未验证。
