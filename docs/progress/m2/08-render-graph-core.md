# M2-08 RenderGraph 依赖与屏障计算阶段报告

- 日期：2026-11-22
- 分支：`task/m2-phase-01-20261122`
- 状态：Linux x64 本地验证完成，Vulkan RenderGraph 执行器尚未开始

## 本阶段交付

- 新增 `rhi/render_graph.hpp`，提供纹理资源、pass 类型、资源读写声明和编译结果类型。
- 根据资源读写关系构建 pass 依赖图并执行稳定拓扑排序，检测循环依赖。
- 支持指定最终输出，反向保留依赖 pass，自动剔除无关 pass。
- 计算被保留资源的首末 pass 生命周期区间。
- 对资源写入前后状态变化生成逻辑屏障记录，供后续 Vulkan 执行器映射到 API 屏障。
- 增加依赖排序、无关 pass 剔除、生命周期和屏障结果测试。

## 验证结果

Linux x64 `linux-dev` 预设的完整构建和 CTest 共 11 项全部通过。RHI 测试验证了写入、读取、最终输出保留和无关 pass 剔除。

## 阶段边界

本阶段只计算逻辑图，不创建 Vulkan 资源，不执行命令，也没有实现瞬态资源内存复用、异步计算跨队列同步或实际 API 屏障映射。资源描述当前只覆盖纹理基础尺寸和格式。Windows x64 和 macOS arm64 尚未验证。
