# M2-03 Vulkan 逻辑设备与队列启动阶段报告

- 日期：2026-11-22
- 分支：`task/m2-phase-01-20261122`
- 状态：Linux x64 本地验证完成，Vulkan 资源和交换链阶段尚未开始

## 本阶段交付

- 新增 `VulkanContext` 生命周期对象，负责 Vulkan loader、实例和逻辑设备的创建与释放。
- 枚举物理设备和队列族，选择图形队列，并为计算和复制队列选择可用队列族，缺少专用队列时回退到已选队列族。
- 创建逻辑设备和图形队列，公开 API 版本、物理设备数量和队列族索引，公共头文件不暴露 Vulkan 类型。
- 为加载器、实例、物理设备、队列族和逻辑设备失败提供明确错误，所有 Vulkan 对象在上下文销毁时按依赖顺序释放。
- 增加逻辑设备启动测试，保留无 Vulkan loader 或无可用 GPU 主机上的可诊断失败路径。

## 验证结果

Linux x64 `linux-dev` 预设的完整构建和 CTest 共 11 项全部通过。当前主机成功创建 Vulkan 实例、物理设备、逻辑设备和图形队列，RHI 测试通过。

## 阶段边界

本阶段没有创建交换链、VMA 分配器、缓冲区、纹理、命令池或 RHI `Device` 的 Vulkan 实现，也没有启用验证回调。Windows x64、macOS arm64 和实际窗口呈现尚未验证。
